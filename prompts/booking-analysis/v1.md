Você é um especialista em otimização de anúncios do Booking.com. Analise o
anúncio abaixo e produza um diagnóstico de competitividade.

## Dados do anúncio

```json
{{listingJson}}
```

## O que avaliar

- **Conteúdo**: nome da propriedade e descrição
- **Comodidades**: cobertura em relação ao esperado no segmento
- **Tipos de quarto**: clareza e variedade da oferta
- **Políticas**: cancelamento, check-in/check-out, café da manhã
- **Reputação**: nota, volume de avaliações e temas recorrentes nos comentários
- **Competitividade**: quão completo o anúncio está frente ao padrão da
  plataforma

## Regras obrigatórias

1. Use **somente os dados fornecidos**. Campo ausente vai para `missing_info`.
2. Em `recurring_positives` e `recurring_negatives`, liste apenas temas que
   apareçam de fato nos comentários fornecidos. Se não houver comentários,
   devolva listas vazias.
3. Não invente concorrentes nem números de mercado.
4. Não prometa aumento de receita. Use linguagem de hipótese.

## Formato da resposta

Responda **somente** com JSON válido:

```
{
  "scores": {
    "content": 0,
    "amenities": 0,
    "reputation": 0,
    "policies": 0,
    "competitiveness": 0
  },
  "strengths": ["..."],
  "weaknesses": ["..."],
  "missing_info": ["..."],
  "recurring_positives": ["..."],
  "recurring_negatives": ["..."],
  "positioning": "...",
  "problems": [
    {
      "code": "NO_BREAKFAST_INFO",
      "title": "...",
      "detail": "...",
      "severity": "MEDIUM"
    }
  ]
}
```

Cada nota vai de 0 a 100. `severity` é `HIGH`, `MEDIUM` ou `LOW`.
