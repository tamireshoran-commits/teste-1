anúncio abaixo e produza o **julgamento qualitativo** que regras automáticas
não alcançam.

```json
{{listingJson}}
```

## Verificações automáticas que JÁ foram feitas

O sistema já rodou regras determinísticas e detectou o seguinte:

```json
{{alreadyFlaggedJson}}
```

E já registrou como informação ausente:

```json
{{alreadyMissingJson}}
```

**Não repita nada dessa lista.** Reescrever um achado com outras palavras
duplica o item no relatório do cliente e faz o mesmo problema ocupar duas
linhas da lista de prioridades.

## O que você deve avaliar

- **Posicionamento**: em que segmento o anúncio se coloca e para quem fala
- **Coerência**: nome da propriedade, descrição e tipos de quarto contam a
  mesma história?
- **Clareza da oferta**: o hóspede entende o que está reservando?
- **Temas nos comentários**: assuntos que se repetem nos comentários
  fornecidos
- **Tom**: o texto gera confiança ou soa descuidado?

## Regras obrigatórias

1. Use **somente os dados fornecidos**; **nunca invente** um valor plausível
   para campo ausente.
2. Em `missing_info`, escreva o nome da informação **em português, como um
   humano diria**, nunca o nome do campo do JSON. Liste apenas o que **não**
   está na lista de ausências já registradas.
3. Em `problems`, inclua somente o que as verificações automáticas não
   cobriram. Se não houver nada, devolva lista vazia.
4. Em `recurring_positives` e `recurring_negatives`, liste apenas temas que
   apareçam de fato nos comentários fornecidos. Sem comentários, devolva
   listas vazias.
5. Não invente concorrentes nem números de mercado.
6. **Não prometa** aumento de receita ou de reservas. Use linguagem de
   hipótese.

## Formato da resposta

Responda **somente** com JSON válido:

```
{
  "scores": {
    "content": 0,
    "amenities": 0,
    "reputation": 0,
    "policies": 0,
    "competitiveness": 0
  },
  "strengths": ["..."],
  "weaknesses": ["..."],
  "missing_info": ["..."],
  "recurring_positives": ["..."],
  "recurring_negatives": ["..."],
  "positioning": "...",
  "problems": [
    {
      "code": "OFFER_UNCLEAR",
      "title": "...",
      "detail": "...",
      "severity": "MEDIUM"
    }
  ]
}
```

Cada nota vai de 0 a 100. `severity` é `HIGH`, `MEDIUM` ou `LOW`.
`positioning` tem no máximo duas frases.
