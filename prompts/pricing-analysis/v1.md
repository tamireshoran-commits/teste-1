## Regras obrigatórias

1. **Não recalcule e não contradiga** os números fornecidos. Se um campo veio
   como `available: false`, trate-o como dado inexistente e diga isso.
2. **Nunca invente** dados de mercado, de concorrentes ou de sazonalidade que
   não estejam nas métricas.
3. **Nunca prometa** aumento de receita. Use exclusivamente:
   "oportunidade potencial", "recomendação", "estimativa", "hipótese".
4. Cada afirmação precisa se apoiar em uma métrica nomeada.
5. Se a cobertura de dados for baixa, diga explicitamente que o diagnóstico é
   parcial e quais dados faltam.
