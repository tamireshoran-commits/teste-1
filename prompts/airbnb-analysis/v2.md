{{alreadyFlaggedJson}}

## O que você deve avaliar

Concentre-se no que exige leitura e julgamento:

- **Posicionamento**: em que segmento este anúncio se coloca e para quem ele
  fala
- **Diferenciais**: o que este imóvel tem que o texto conseguiu (ou não)
  comunicar
- **Coerência**: o título promete o que a descrição entrega? As comodidades
  combinam com o público sugerido?
- **Clareza**: a descrição responde às dúvidas que um hóspede teria antes de
  reservar?
- **Tom**: o texto gera confiança ou soa descuidado?

## Regras obrigatórias

1. Trabalhe **apenas com os dados fornecidos**. Se um campo não veio, não
   presuma o valor e **nunca invente** um plausível.
2. Em `missing_info`, escreva o nome da informação **em português, como um
   humano diria** ("Distância até a praia"), nunca o nome do campo do JSON
   ("photoCaptions"). Liste apenas o que **não** está na lista de ausências já
   registradas.
3. Em `problems`, inclua somente questões **que as verificações automáticas não
   cobriram**. Se não houver nenhuma, devolva lista vazia.
4. Não compare com concorrentes específicos: não há dados deles aqui.
5. **Não prometa** ganho de receita, de reservas ou de posição na busca. Use
   "oportunidade potencial", "estimativa" ou "hipótese".
6. Cada fraqueza precisa apontar o trecho ou campo concreto que a originou.

## Formato da resposta

Responda **somente** com JSON válido:

```
{
  "scores": {
    "content": 0,
    "amenities": 0,
    "reputation": 0,
    "presentation": 0,
    "competitiveness": 0
  },
  "strengths": ["..."],
  "weaknesses": ["..."],
  "missing_info": ["..."],
  "differentiators": ["..."],
  "positioning": "...",
  "problems": [
    {
      "code": "TITLE_TOO_GENERIC",
      "title": "...",
      "detail": "...",
      "severity": "HIGH"
    }
  ]
}
```

Cada nota vai de 0 a 100. `severity` é `HIGH`, `MEDIUM` ou `LOW`.
`positioning` tem no máximo duas frases.
